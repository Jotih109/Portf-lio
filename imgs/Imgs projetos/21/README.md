### 📝 Descrição Sugerida para LinkedIn / GitHub / BeHance:

> **OVERVOLTAGE 21** é um jogo tático de cartas e sobrecarga numérica desenvolvido em JavaScript Vanilla e CSS puro, inspirado na estética *Cyber-Grindhouse / CRT VHS* e no modo 21 de Resident Evil 7 e Balatro.
>
> 🚀 **Destaques do Projeto:**
> - **Zero dependências externas:** Construído 100% com HTML5 semântico, Vanilla CSS e Vanilla JS moderno.
> - **Sistema de Trunfos & Modificadores:** Habilidades ativas como visão de raio-x, permuta neural, alteração de regras da rodada e escudos.
> - **5 IAs com Comportamentos Únicos:** Algoritmos adaptativos que calculam probabilidades de compra e utilizam trunfos conforme o nível de risco.
> - **Interface Imersiva:** HUD dinâmico com aberração cromática, scanlines CRT, partículas em Canvas e layout responsivo para desktop e mobile.
