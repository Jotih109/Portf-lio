## 📝 Textos Prontos para Usar no seu Portfólio

### 🔹 Para o GitHub README ou Descrição de Projeto
```markdown
# 🐶 QuizDOG — Jogo Interativo das Raças Caninas

Uma aplicação web interativa, moderna e responsiva construída com **JavaScript Puro (Vanilla)** e **CSS3 Avançado**, consumindo a **Dog CEO REST API**.

### ✨ Principais Recursos:
- **Dois Modos de Jogo:** Múltipla Escolha (com atalhos rápidos [1-4]) e Modo Digitação livre.
- **Dicionário PT-BR Completo:** Tradução e normalização automática de dezenas de raças para Português do Brasil.
- **Efeitos Audiovisuais Nativos:**
  - Sistema procedural de partículas de confete via **HTML5 Canvas 2D**.
  - Efeitos sonoros gerados dinamicamente via **Web Audio API** (sem arquivos de áudio externos).
- **Gamificação:** Contadores de acertos, erros, sequências (streak em chamas 🔥) e recordes com persistência via `localStorage`.
- **Tema Claro / Escuro:** Alternância instantânea com suporte a variáveis CSS e glassmorphism.
- **Zero-Scroll UX:** Interface planejada para caber confortavelmente em qualquer resolução desktop e mobile.

### 🛠️ Tecnologias Utilizadas:
- **HTML5 Semântico**
- **CSS3 Moderno** (Flexbox, CSS Grid, Glassmorphism, CSS Custom Properties, Animações Keyframes)
- **JavaScript ES6+** (Fetch API, Promises, Async/Await, Canvas API, Web Audio API, LocalStorage)
- **Dog CEO REST API**
```
